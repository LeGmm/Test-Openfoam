一、这个实验实现了什么功能

把湿空气冷凝从 Fluent 的 Lee 经验模型 移植到 OpenFOAM，构建了一条两步共轭传热 + 冷凝管线， 用于比较不同冷凝器几何结构的冷凝效果：

环节求解器 / 工具做什么物理意义
Step 0 转换 + 门禁fluent_cas_to_foam_cht.py / preflight.py Fluent cas.h5 → fluid+solid 双区域 polyMesh；10 项开跑前检查 保证网格/字典/耦合边界在起跑前合规
Step 1 共轭传热chtMultiRegionFoam 流体（湿空气）+ 固体（铝，含空腔）稳态共轭传热；仅冷板定 278.15 K 算出真实的流固界面温度分布 T_int(x)——不是把界面拍成 5℃ 一刀切
Step 1.5 提取/校验map_interface_T.py extract/verify 提取 9459 个界面面心温度；同网格一致性 gate 保证映射不串位（实测偏差 0.000001 mm）
Step 2 冷凝相变multiphaseEulerFoam T_int 映射为 coldWall 非均匀边界；气液双流体 + 界面组分相变 水蒸气经不凝气体（空气）Stefan 扩散到界面凝结——含不凝气体冷凝的物理正确做法
Step 3 指标对比compare.py ṁ_cond / Y_H2O_out / T_out / Q_wall / Δp 五指标 定量排名 8 个结构的冷凝效率

方法学上做对的地方（这些是论文的卖点）

  • 冷源位置正确：wall_cool（5℃ 面）是固体外表面而非流固界面。早期方案把界面直接定 5℃ 属于过度冷却、 冷源悬空——该方案已否决并改为两步共轭。这是本项目在物理建模上最重要的修正。
  • 相变模型更先进：Fluent Lee 模型是温度驱动经验式（需标定频率系数 β）；本项目用界面饱和 （ArdenBuck）+ 不凝气体扩散（Stefan 流），直接对应 SOP 强调的"不凝气体扩散阻力"，无需标定系数。
  • 可测指标设计正确：ṁ_cond（凝液质量流率）、Y_H2O_out（出口含湿）、Q_wall（冷壁换热）、Δp 正是衡量冷凝器性能的标准量，且配了守恒校核（质量 <2%、能量闭合）。

二、结果是否可靠？—— 分项审计

2.1 Step1（共轭传热）：物理正确，但未严格收敛

已验证通过的：质量守恒 m_in = m_out = 1.99985×10⁻⁵ kg/s（8 位有效数字一致）； 界面温度梯度物理合理（冷板在 +z，z=+20mm 处 280.4K → z=−20mm 处 297.9K，单调）； T_int 提取 verify PASS（9459↔9459 面心重合）；preflight 门禁 PASS。
核心问题：能量平衡没有闭合。按控制体定律，稳态时必须满足 ṁ·cp·(T_in−T_out) = Q_interface。实测（取自 postProcessing/fluid/ 数据文件）：

  • 同时 h 方程初始残差 = 9.7×10⁻⁴，未达 10⁻⁶ 量级判据；T_out 每 50 次迭代仍漂移 0.8 K。

  • 后果：映射给 Step2 的 T_int 是暂定场。界面均值 291.5 K，若继续迭代，界面还会整体降温 （T_out 理论极限约 283 K 量级），结露面积比例会变。

科学意义：这组数字本身就是结构冷凝效率的诊断——v8_1 有 近 6 成换热面根本不结露， 有效冷表面利用率只有 20%。也就是说，该结构的冷量没有被充分"铺开"，冷板只影响了 +z 端。 这对"冷凝器结构对比"是核心论据之一，而且这一步不依赖 Step2，可以先写。

3.2 若 Step2 跑通，能得到什么

  • ṁ_cond：凝液质量流率——冷凝效果的直接度量，结构间可比；
  • Y_H2O_out：出口水蒸气质量分数——除湿效率；
  • Q_wall：冷壁换热量——与潜热释放配平做能量闭合校核；
  • Δp：压降——代价侧指标（换热 vs 流阻）；
  • 凝液空间分布（alpha.liquid 场）——看膜状/滴状、是否沿 −Y 重力排出。

四、能否衡量冷凝器结构对应的冷凝效果

维度判定依据
方法学上能不能能 指标设计正确；两步共轭抓住了"固体导热路径 → 界面温度分布 → 局部结露"这条结构敏感链路； 相变模型含不凝气体扩散阻力，物理上比 Lee 经验式更站得住
现在拿数据能不能不能 Step2 零有效结果；仅 v8_1 一个结构跑了 Step1 且未收敛；其余 7 个结构未开始； comparison.csv 现有行是初始值不是结果
补完工作后能不能能 障碍是数值稳定性（薄片单元 + 相变刚性），属可解决的工程问题，不是方法学死路

已知会干扰结构对比的缺陷（写论文必须披露）

  1. 单向耦合：凝液潜热不反馈固体温度。对凝液量大的工况会低估界面温度回升， 必要时用 Step2 的 Q_wall 反代 Step1 迭代一次。
  2. v8_12 / v8_13 / v8_14 有无网格空腔（两块 2mm 板间 17mm 间隙无气体无固体，两壁各 13.34 cm² 互不耦合）——这是 CAD/设计层面缺陷，会在共轭热路里真实呈现为断路，三个结构的对比要单独说明。
  3. 薄片单元层（各结构均有，v8_1 为 7625 个 / 11.8%）：既是 Step2 崩溃根源，也是 Step1 局部 q 高达 4.6 kW/m² 的来源，网格无关性研究必须做。
  4. 铰链 pinch（1 对单元共棱双面）：已定性为合法拓扑、不阻塞守恒，保留不动；论文中可一句带过。
  5. Euler 分散相模型近似膜状冷凝：对液膜形态是近似；只比"量"可接受，比"膜厚/形态"需转 VOF。
  6. 无实验验证、无网格无关性（GCI）——期刊审稿人必问的两项，目前都缺。

六、距离"可投稿"还差什么（按优先级）

  1. P0 — Step1 跑到真收敛：endTime 提到 1000+，监控能量平衡比值 →1（<5%）与 h 残差 <1e-6； 用同一套 FO 出 Q_coldWall，做固体侧能量闭合（现在只有流体侧）。预计单次约 10 分钟量级。
  2. P0 — Step2 数值稳定：三条路线任选其一——(a) 固定小时间步 1e-6 起步 + 局部限速； (b) 薄片层局部加密（Fluent 侧进出口面下加密一层，重导出）；(c) 相变源项亚松弛/限幅。 目标：推进到秒级、ṁ_cond 与 Y_H2O_out 出稳态平台。
  3. P1 — 至少 3 个结构跑通全流程（建议 v8_1 / v8_8 / v8_12，避开空腔缺陷先做干净对比，空腔结构单独讨论）。
  4. P1 — 网格无关性（GCI）：冷壁与相变区加密一档，两套网格指标差 <5%。
  5. P2 — 单向耦合补偿：用 Step2 的 Q_wall 反代 Step1 冷壁热流迭代一次，量化潜热反馈误差。
  6. P2 — 若期刊要求：实验对标（哪怕一组工况的 ṁ_cond 或 T_out）。
