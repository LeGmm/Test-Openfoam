一、Step1 与 Step2 是什么

把湿空气冷凝拆成两步，是因为没有任何一个 OpenFOAM 求解器能同时算"固体导热 + 多相冷凝"： multiphaseEulerFoam 不能带固体区，而 chtMultiRegionFoam 没有相变。于是：

Step 1 共轭传热Step 2 冷凝相变
求解器chtMultiRegionFoammultiphaseEulerFoam
算什么湿空气（单相）+ 铝固体（含空腔）一起导热， 只有 5℃ 冷板定温 278.15K，求出流固界面的真实温度分布 T_int(x) 气液两相湿空气冷凝：水蒸气经不凝气体（空气）Stefan 扩散到冷壁凝结， T_int 映射成冷壁的非均匀温度边界
为什么必要5℃ 冷板是固体外表面不是流固界面；把界面直接拍成 5℃ 会过度冷却、冷源悬空（早期方案已否决） 相变模型比 Fluent Lee 经验式物理上正确（含不凝气体扩散阻力，无需标定系数）
输出T_int 场（9459 面）→ 映射给 Step2 ṁ_cond / Y_H2O_out / T_out / Q_wall / Δp 五项冷凝指标

两步之间是单向耦合：凝液潜热不反馈 Step1 的固体温度（论文须披露； 可用 Step2 的 Q_wall 反代迭代一次补偿）。

二、优化一：Step1 跑到真收敛

2.1 加了什么

  • 质量加权温度 FO（T_in_mw / T_out_mw，phi 加权）：能量守恒核对必须用通量加权温度， 原来的面积平均在速度不均时会失真；
  • 固体侧热流 FO（Q_solid，region solid）：一次给出 interface / coldWall / outer 三行—— outer≡0 通过绝热核对 ✓，interface 与流体侧配对核对 ✓；
  • 续跑 400 → 1400 → 3400 → 5400（在跑）次外迭代。

3.2 根因（单元级实锤）

t=4µs 时温度异常（<250K 或 >350K）的 5546 个单元，100% 是小体积单元 （V < 3.4e-11 m³，全域体积中位数 2.1e-10）；其余 5.9 万个单元温度完全正常（278~308K）。

机制与项目内 fix_zero_volume_cells.py 文档描述的病完全一致： 薄片单元 Ap = V/dt ≈ 0 → 压力方程系数 1/Ap 发散 → 速度爆炸（Co 0.0055→141 只要 1 步）→ 温度飞掉。薄片的几何形态是"双大面平行（面心仅隔 0.4µm）+ 微小侧面相连"的退化枢纽片， 集中在进出口平面（y≈+30mm）下方。

节点偏移修复法对这类薄片无效（本轮实测）：把 7626 个薄片单元的最大面节点沿法向偏移 0.05mm， 体积平均只涨 5%，还把邻居单元挤小（最小体积反而 8.8e-13 → 2.2e-13）； 1339 个单元"偏移后仍无体积"被跳过。需要整面平移或上游 Workbench 在进出口面下加密一层 （《网格修复指南.md》早已给出的路线）。网格已从 cas.h5 重新生成回干净状态。

3.3 本轮修掉的次生问题（保留，都有用）

  • 液侧 Henry 关闭：air.liquid 方程在 alpha≈1e-6 残余下退化（残差恒为 1）， 是爆温链条一环；空气溶解对冷凝量是二阶小量；
  • 液滴直径 1e-4 → 5e-4：界面传质/传热系数 K∝1/d，降低源项刚性；
  • nAlphaSubCycles 1 → 3：压制 MULES 过/欠冲（曾出现负 alpha 与相和 >1）；
  • 新工具 tools/warmstart_step2.py：T/U/p_rgh 从 Step1 按单元热启动 （两网格单元序已核验一致：质心差 3.6e-18 m，差异只在边界面书写顺序）+ 组分饱和度自洽初始化。 热启动消除了"T 场冷 + Y 场湿"的人为过饱和爆发，是生产运行的正确起点。
